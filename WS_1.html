3.4 1. Importing data

In practice, you will normally import data from a file given to you.

Hence, importing data typically require two things. 1. You know the command to load in the data 2. You know both the file path and filename.

Then, if you continue to use google colab for your projects. You can give access google colab access to your google drive, and load files through google drive. Although we will not be utilizing this here. The code for mounting your google drive is below.

# Code for "mounting" (giving google colab access to) google drive
# We will not be using this, but is good to know
#from google.colab import drive
#drive.mount('/content/drive')

Once you have access to data through a CSV or an excel file, to load in data from either file types, we will use the following pandas functions:

pd.read_csv(‘/filepath/file_name.csv’)

pd.read_excel(‘/filepath/file_name.xlsx’)

We will then associate each of these sets of data with a data frame ( in code we denote “df” ).

4 2. Cleaning Data

When dealing with sets of data, whether it come from a survey you took, or from an online resource it may not have formatting you would like. Or, it may have information you do not care about. Our goal in this note book will be to touch on the basics of cleaning data

  • Removing duplicates
  • Removing NaN’s (Filling them in with a blank string)
  • Removing columns

The basic commands will be

df_foo.drop_duplicates()

df_foo.fillna(““)

df_foo.drop(columns = “COLUMN_NAME”)
